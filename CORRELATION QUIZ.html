Part I: Identification • Item 1 / 5
Question 1

What statistical test is used to measure the strength and direction of a linear relationship between two continuous/numerical variables?

Correct Answer: Pearson's r (Pearson Product-Moment Correlation)

Pearson's r measures continuous/numerical data that exhibits an approximately linear relationship.

Part I: Identification • Item 2 / 5
Question 2

What non-parametric test evaluates the strength and direction of association between two ranked or ordinal variables using their rank values instead of raw numbers?

Correct Answer: Spearman's Rank Correlation

Spearman's rank correlation calculates association based on ordinal rankings rather than continuous values.

Part I: Identification • Item 3 / 5
Question 3

What statistical method is used to study relationships and predict an outcome variable based on independent predictor variables?

Correct Answer: Linear Regression

Linear Regression establishes a line of best fit (Y = a + bX) to estimate or predict an unknown value from known predictor values.

Part I: Identification • Item 4 / 5
Question 4

In regression analysis, what is the variable being predicted or estimated called (represented as Y)?

Correct Answer: Dependent Variable (or Outcome Variable)

The variable being predicted is the Dependent Variable (Y), whereas the variable used to make predictions is the Independent Variable (X).

Part I: Identification • Item 5 / 5
Question 5

What statistic measures the difference between ranked values (Rx - Ry) when computing Spearman's rank correlation coefficient?

Correct Answer: Rank Difference (d)

The variable d represents the difference between paired ranks (d = Rx - Ry).

Problem 1: Pearson's r

A researcher collected study hours (X) and test scores (Y) for 5 students. Calculate Pearson's r:

StudentStudy Hours (X)Test Score (Y)
A260
B470
C680
D890
E10100
Formula: r = [nΣXY - (ΣX)(ΣY)] / √([nΣX² - (ΣX)²][nΣY² - (ΣY)²])

Key Answer: r = 1.0

• n = 5
• ΣX = 30, ΣY = 400
• ΣX² = 220, ΣY² = 33,000, ΣXY = 2,600

r = [5(2600) - (30)(400)] / √([5(220) - 30²][5(33000) - 400²])
r = 1000 / √(200 × 5000) = 1000 / 1000 = 1.0 (Perfect Positive Correlation)

Problem 2: Spearman's Rank Correlation

Grades of 7 students in English (X) and Math (Y). Rank each set from 1 (highest) to 7 (lowest) to calculate Spearman's rs:

StudentEnglish (X)Math (Y)
A7885
B8082
C8175
D8677
E7980
F8390
G8892
Formula: r_s = 1 - (6Σd²) / [n(n² - 1)]

Key Answer: rs = 0.214

Rank Assignments (Highest = 1):

  • Student A: Rx=7, Ry=3 | d=4, d²=16
  • Student B: Rx=5, Ry=4 | d=1, d²=1
  • Student C: Rx=4, Ry=7 | d=-3, d²=9
  • Student D: Rx=2, Ry=6 | d=-4, d²=16
  • Student E: Rx=6, Ry=5 | d=1, d²=1
  • Student F: Rx=3, Ry=2 | d=1, d²=1
  • Student G: Rx=1, Ry=1 | d=0, d²=0

Σd² = 44, n = 7
rs = 1 - [6(44) / (7 × 48)] = 1 - (264 / 336) = 0.214
